
# Student Management System

## Project Description
A simple Student Management System developed
using Python and Object-Oriented Programming (OOP).

## Features
- Store student information
- Calculate average percentage
- Check pass or fail status
- Display student details

## OOP Concepts
- Classes and Objects
- Constructor (__init__)
- Instance Attributes
- Methods
- List Operations

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run: python main.py
